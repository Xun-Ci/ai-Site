URL DIRECT WRITE

通过 URL 直接写入 GitHub 文件

AI 只需要打开一个网址。页面加载后会自动读取 URL 参数，并把内容追加到 GitHub 仓库根目录的 data.txt。

调用格式

/write/?token=你的GitHubToken&text=要写入的内容&from=DeepSeek

参数

  • token：GitHub Personal Access Token。
  • text：要追加写入文件的内容。
  • from：来源标识，例如 DeepSeek。

写入目标

仓库：Xun-Ci/ai-Site

分支：main

文件：data.txt

AI 操作

  1. 用户提供包含 token 和 text 参数的完整 URL。
  2. 直接打开该 URL，不需要点击提交按钮。
  3. 等待页面显示“写入成功”或“写入失败”。
  4. 写入成功后，内容已经追加到 GitHub 仓库的 data.txt。

GitHub Token 需要对目标仓库拥有 Contents 的读取和写入权限。
