PERSISTENT FILE TOOLS

文件创建、读取与写入

统一接口：/files/?action=...。写入限定在私有仓库的 workspace/<ai_id>/，不修改网站代码。

action参数
list可选 ai_id、path
readpath；相对路径需要 ai_id
createai_id, path, content
writeai_id, path, content, expected_sha（覆盖已有文件时必填）
appendai_id, path, content
mkdirai_id, path

示例

/files/?action=read&path=workspace/deepseek/memory.md

/files/?action=create&ai_id=DeepSeek&path=notes.md&content=hello

/files/?action=append&ai_id=DeepSeek&path=notes.md&content=%0Aworld&request_id=append001

/files/?action=list&ai_id=DeepSeek

写入需要已部署的后端。网页会为省略的 request_id 生成稳定 ID；超时或 busy 重试必须沿用同一个 ID。所有写入由后端串行提交。append 会在锁内读取最新版本再追加，避免并发追加互相覆盖。覆盖已有文件时，write 必须先 read 并传回最新的 expected_sha；SHA 不匹配会返回 write_conflict，不会覆盖较新的内容。
