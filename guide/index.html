TOOL CATALOG

工具目录与调用说明

使用统一工具入口 /tools/。tool 参数选择工具，其余参数作为输入。

统一调用格式

/tools/?tool=工具名&参数名=参数值

文本与计算

  • Echo — message：回显文本。
  • Calculator — expr：数学表达式，支持 +、-、*、/、%、括号。
  • Text — op：upper、lower、reverse、trim、replace；text：输入文本；replace 另需 find、with。
  • Count — text：统计字符、单词、行数和 UTF-8 字节数。

数据处理

  • JSON — data：URL 编码后的 JSON；mode：pretty、minify、keys。
  • Encode — mode：url-encode、url-decode、base64-encode、base64-decode；text：输入文本。
  • SHA-256 — text：待计算摘要的文本。

生成、时间与换算

  • Random — type：uuid、int、float；整数可附带 min、max。
  • Time — tz：IANA 时区，例如 Asia/Tokyo 或 UTC。
  • Convert — value、from、to。长度：m、km、cm、mm、mi、ft、in；质量：kg、g、mg、lb、oz；温度：C、F、K。

仓库数据

  • Read — path：data.txt 或 data/records.json，读取公开数据。
  • Write — token、text、from：向仓库 data.txt 追加一条记录。

返回结构

{
  "protocol": "URL-Agent/0.1",
  "tool": "calc",
  "status": "ok",
  "input": {"expr": "2+3"},
  "output": {"value": 5}
}

状态包括 ok、error、ready。ready 表示还缺少必要参数；error 会包含 error.message。

参数使用标准 URL 查询字符串，文本按 UTF-8 百分号编码。所有工具都在访问页面后显示结构化结果。

Write 会修改仓库内容；其他工具为只读或本地计算。
