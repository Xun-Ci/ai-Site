TOOL CATALOG

工具目录

路径入口与参数说明。所有工具结果以页面文本和 JSON 形式呈现。

工具入口

  • echo：message，回显文本。
  • calc：expr，数学表达式。
  • text：op=upper|lower|reverse|trim|replace；text；replace 另需 find、with。
  • count：text，统计字符、单词、行、UTF-8 字节。
  • json：data；mode=pretty|minify|keys。
  • encode：text；mode=url-encode|url-decode|base64-encode|base64-decode。
  • random：type=uuid|int|float；int 可用 min、max。
  • time：tz，IANA 时区名。
  • convert：value、from、to。长度 m/km/cm/mm/mi/ft/in；质量 kg/g/mg/lb/oz；温度 C/F/K。
  • hash：text，SHA-256。
  • read：path=data.txt|data/records.json。
  • write：token、text、from，追加到 data.txt。

返回结构

{"protocol":"URL-Agent/0.1","tool":"calc","status":"ok","input":{"expr":"2+3"},"output":{"value":5}}

参数采用 URL 查询字符串，文本使用 UTF-8 百分号编码。工具页面会显示实际执行结果。

写入工具会修改仓库；其余目录工具为只读或纯计算操作。
