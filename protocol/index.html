URL-Agent Protocol v0.1

一种以普通网页 URL 表达工具入口、输入参数和可读取结果的实验性接口约定。

接口结构

https://host/tools/?tool={tool-name}&{input-parameters}
  • URL 路径指向工具执行页面。
  • tool 参数选择具体工具。
  • 其他查询参数提供工具输入。
  • 页面展示执行状态和 JSON 输出。

统一结果结构

{
  "protocol": "URL-Agent/0.1",
  "tool": "tool-name",
  "status": "ok",
  "input": {},
  "output": {}
}

status 可为 ok、error 或 ready。error 结果包含 error.message；ready 结果描述缺少的参数。

参数编码

使用标准 URL 查询字符串，多个参数用 & 分隔，文本使用 UTF-8 百分号编码。

协议定位

URL-Agent Protocol 是本项目提出的实验性约定，不是已注册的互联网标准，也不是 MCP 的官方替代协议。它复用普通 HTTPS 网页、URL 路径和查询参数，使浏览器型客户端能够通过访问网页使用工具。

执行类型

多数工具在浏览器中本地执行；Read 读取公开仓库文件；Write 通过 GitHub API 修改 data.txt。Write 属于有副作用的接口，需要 GitHub Token。

将 Token 放入 URL 可能使其出现在浏览器历史或请求日志中。实验时应使用权限受限且短期有效的 Token。
