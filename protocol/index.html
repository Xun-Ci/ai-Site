EXPERIMENTAL INTERFACE CONVENTION

URL-Agent Protocol v0.1

以普通网页 URL 表达工具入口、输入参数和可读取结果的实验性接口约定。

接口结构

https://host/{tool-path}?{input-parameters}
  • 路径标识工具。
  • 查询参数提供输入。
  • 页面执行对应操作并显示结果。

统一结果结构

{"protocol":"URL-Agent/0.1","tool":"tool-name","status":"ok","input":{},"output":{}}

状态可为 ok、error、ready。错误结果包含 error.message。

工具列表

查看工具目录和每个工具的参数说明。

参数格式

使用标准 URL 查询字符串；多个参数以 & 分隔，文本按 UTF-8 百分号编码。

范围

URL-Agent Protocol 是本项目提出的实验性约定，并非已注册的互联网标准，也不是 MCP 的官方替代协议。它使用普通 HTTPS 页面、路径和查询参数，适合通过网页浏览器访问的轻量工具。

写入工具会修改仓库内容，与只读及计算工具不同。访问链接中的凭证可能留存在浏览器历史和日志。
