TOOL 12 · STORAGE · WRITE

追加 GitHub 记录

读取 URL 参数，将一条 JSON 记录追加到仓库根目录的 data.txt。

参数

  • token：对 Xun-Ci/ai-Site 有 Contents 读写权限的 GitHub Token。
  • text：要追加的文本。
  • from：来源标识，可选，默认 agent。

调用格式

/write/?token=TOKEN&text=Hello%20Agent&from=agent
此工具会修改 GitHub 仓库。Token 放在 URL 中可能出现在浏览器历史和请求日志中。

执行状态

等待 URL 参数

结构化结果

{"protocol":"URL-Agent/0.1","tool":"write","status":"ready"}
